# Campfire 视觉方向（Art Direction）

## 一句话定位

**Semi-realistic / realistic cozy night campsite** ——
一个真实存在过、被人用过的夜间营地：安静、温暖、略有风霜，镜头感克制，一切光影都说得通。

| 关键词 | 在画面里的意思 |
|---|---|
| quiet 安静 | 画面留白多；只有火是"动"的中心，其余元素不抢戏；不加镜头光晕、泛光爆炸 |
| warm 温暖 | 火光是唯一真正的暖色主光；暖色只出现在火能照到的地方 |
| lived-in 有人住过 | 物品有使用痕迹、摆放不完全对齐：帐门卷起、睡袋露在门口、斧头插在桩上 |
| slightly weathered 略有风霜 | 旧化是"用过几年"而不是"废墟"：褪色、泥点、烟熏、磨损边缘 |
| natural 自然 | 材质颜色来自真实世界的反照率范围；形状符合受力（布料垂坠、绳子绷紧） |
| cinematic but not exaggerated 有电影感但不夸张 | 明确的冷暖对比与剪影层次，但不用高饱和、不用夸张体积光 |
| physically plausible 物理上说得通 | 平方反比衰减、ACES 色调映射、PBR 材质；灯的亮度、影子方向、谁挡住了谁都能解释 |

**反面清单**：产品展示模型（崭新、锐利、干净）；卡通高饱和；塑料感纯色材质；所有东西一样亮；
没有接触阴影、像贴在地面上；"为了显得精细"而堆砌的微小几何。

## 光照结构

```
        月光（冷、弱、低角度）+ 夜空天光
                    ↓
        冷蓝环境：远山、林线、地面、剪影
                          ↘
                     Campfire 篝火
                     暖橙主光（最亮、投影、闪烁）
                    ↙                ↘
              Tent 帐篷             Props 道具
       （向火一侧暖、背面冷；       （近火处暖、远离处
         门内一盏小暖灯）             回落到冷环境色）
```

| 光源 | 色温 / 颜色 | 角色 | 规则 |
|---|---|---|---|
| 篝火 `FireLight` + `FireFill` | 约 1800 K，0xff7a28 | 主光 | 唯一的强投影光；影子随火舌抖动；强度随燃料变化 |
| 月光 `MoonLight` | 冷蓝 0x91a8d0 | 轮廓光 | 低角度（仰角 ≈ 13°），只勾勒朝月面，不压过火光 |
| 天光 `SkyLight`（半球光） | 冷蓝 / 暗土 | 环境光 | 让火光外的物体读得出形体，但保持"夜"的暗度 |
| 提灯 `LanternLight` | 约 2200 K，0xffb259 | 局部点缀 | 只照亮 1~2 m 范围；油壶挡住正下方 |
| 帐内灯 `TentGlow` | 约 2700 K，0xffb26a | 叙事光 | 只从门洞漏出一点暖色，告诉观众"有人在里面" |
| 火把 | 同篝火 | 临时 | 点燃时才出现 |

**冷暖关系必须一眼可见**：同一物体上，向火面暖、背火面冷；离火越远越冷、越暗。
不要用提高曝光或环境光强度来"看清楚"，那会冲掉冷暖对比。

## 色调映射与曝光

- ACES Filmic，默认曝光 1.1（参数面板可调）；
- 火焰粒子、余烬、灯芯允许进入高光肩部（发光体可以接近白），**被照亮的表面不应过曝**；
- 发光强度（emissive）只给真正发光的东西：火苗、余烬、灯芯、帐内小灯。帆布、玻璃不自发光。

## 材质原则（PBR）

| 类别 | 反照率（sRGB 大致范围） | 粗糙度 | 金属度 | 旧化方式 |
|---|---|---|---|---|
| 帆布（帐篷、背包） | 中暗：橄榄绿/卡其/土红 | 0.75–0.95 | 0 | 顶部日晒褪色、下沿泥点、接缝积灰、向火面轻微烟熏 |
| 织带 / 绳子 | 中 | 0.8–0.95 | 0 | 起毛、脏污 |
| 喷漆金属（提灯、椅架） | 暗 | 0.4–0.7 | 0（漆面）/ 1（掉漆处） | 边缘掉漆露金属、烟熏、指纹油污 |
| 黄铜 | 暖黄 | 0.3–0.5 | 1 | 氧化变暗、凹处发绿 |
| 铸铁 / 铁壶 | 很暗 | 0.6–0.85 | 0.6–1 | 底部烟熏、热变色（蓝紫/褐色回火色）、水垢 |
| 玻璃 | 近透明 | 0.05–0.15 | 0 | 顶部烟熏、灰尘 |
| 木头（柴、柄、桩） | 中暗褐 | 0.8–0.95 | 0 | 树皮裂纹、截面年轮、焦黑炭化 |

- 反照率不要低于 ≈ 3%（线性）——"纯黑材质"在弱光下会变成死黑剪影；也不要高于 ≈ 80%。
- 每个道具都需要法线/粗糙度的**细节变化**，不能只靠 `color` 参数表现材质。
- 旧化是低频、有逻辑的：泥点在下沿、烟熏在向火侧和顶部、磨损在边角。

## 形体与细节

- **轮廓优先**：夜景里剪影比细节重要。帐篷的脊线下垂、拉绳、地钉，提灯的提梁，椅子的 X 腿——这些决定轮廓的部件必须准确。
- **受力合理**：布料在支撑点之间下垂、在拉点附近出现放射状张力褶；绳子绷直；物体贴地有接触面。
- **细节层级**：
  1. 大形（剪影、比例）——几何；
  2. 中形（接缝、厚度、褶皱、扣具）——几何 + 法线；
  3. 微观（织纹、木纹、划痕）——法线/粗糙度贴图。
  不要用几何去做第 3 层。

## 场景层次

1. **前景营地**（0–5 m）：精细 GLB 道具，火光主导，暖。
2. **中景树林**（5–60 m）：程序化针叶树，天光 + 月光，冷，剪影为主。
3. **远景山脉**（60 m+）：程序化山体，大气透视融入地平线。

每一层的亮度和对比度逐层降低；火是全画面最亮、最暖的点。
