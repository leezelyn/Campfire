Three.js で作られた、インタラクティブな夜の焚き火シーンです。  
プロジェクトは主に単一の `index.html` ファイルで構成されており、Three.js は CDN から読み込まれます。ビルドや依存関係のインストールは不要です。

---

## 概要

**Campfire** は、ブラウザ上で動作する夜の焚き火デモです。粒子による炎、火の粉、煙、月明かり、霧、天気調整、Web Audio によるプログラム生成サウンドを組み合わせ、静かな夜のキャンプの雰囲気を表現しています。

以下の学習や実験に役立ちます。

- Three.js による 3D シーン構築
- 炎、火の粉、煙の粒子表現
- Web Audio による音の生成
- 3D 空間音響と距離減衰
- 簡単な物理シミュレーション
- リアルタイムなパラメータ調整
- 多言語 UI

## 主な機能

### 夜の焚き火シーン

炎、薪、火の粉、煙、月明かり、霧、雲量、小雨、夜の環境光を組み合わせ、インタラクティブなキャンプ空間を作ります。

自然環境はすべて手続き的にモデリングしています：

- **針葉樹**：トウヒ（垂れ下がる輪生枝の層、先の尖った枝先）とマツ（高い幹と房状の樹冠）。幹は樹冠を貫き、根張りと樹皮テクスチャ付き。中景にはインスタンス化した背景林
- **遠くの山**：リッジ型マルチフラクタルによる山脈が一周し、地面と継ぎ目なくつながる。標高と傾斜で林帯・岩肌・雪を塗り分け、月と湖の方向は低く抑えて月を隠さない
- **地形**：グラディエントノイズ fBm の起伏。キャンプと湖は平らで、山麓に向かって林床がゆるやかに上がる
- **海辺**：海へ落ち込む岬となる海岸の丘、岩礁、羽状複葉のヤシ

### リアルタイム調整パネル

画面右上のパネルから、以下の項目をリアルタイムで調整できます。

- 炎の強さ
- 熱による上昇力
- 火の粉の発生量
- 煙の量
- 風速
- 全体音量
- パチパチ音の頻度
- 距離減衰
- 空気による高音域の吸収
- 小雨
- 雲量
- 月相
- 月明かりの強さ
- 霧の濃さ
- 画面露出

すべての変更は即座に反映されます。

### 薪をくべる操作

下部の **薪をくべる** ボタンを押すと、薪がカメラ側から放物線を描いて焚き火に投げ込まれます。

この操作では以下の表現が行われます。

- 放物線運動
- 回転アニメーション
- 火の粉の発生
- 煙の発生
- 3D 位置に基づく着地音
- 燃料の増加
- 炎の強化
- 一時的なパチパチ音の増加

燃料は時間とともに燃焼し、炎の勢いも徐々に落ち着いていきます。

### 焚き火インタラクション

以下の 4 種類のインタラクションがあります。

- **マシュマロを焼く**：マシュマロを火に近づけ、徐々に焦げ目をつけます。
- **お湯を沸かす**：ケトルを炎の上に吊るし、加熱後に蒸気を発生させます。
- **たいまつに火をつける**：たいまつを炎に近づけて点火し、もう一度押すと消火できます。
- **松ぼっくりを投げる**：松ぼっくりを火に投げ入れ、火の粉を散らして少量の燃料を追加します。

### 三言語対応 UI

UI は以下の三言語に対応しています。

- 中文
- English
- 日本語

ボタン、状態表示、進行状況などが即時に切り替わります。

### プログラム生成サウンド

すべての音は Web Audio API によってリアルタイム生成されます。外部音声ファイルは不要です。

生成される音の例：

- 炎の低い燃焼音
- 薪のパチパチ音
- ときどき発生する破裂音
- 薪が落ちる鈍い音
- 距離による音量減衰
- 遠くなるほど高音が弱くなる空気吸収表現

## 実行方法

このプロジェクトは ES Module を使用しているため、ローカル HTTP サーバー経由で開くことを推奨します。

```bash
python -m http.server 8341
```

その後、ブラウザで以下にアクセスします。

```text
http://localhost:8341
```

ページを開いた後、任意の場所をクリックすると音声が有効になります。  
これは、多くのブラウザが Web Audio の再生にユーザー操作を必要とするためです。

## 3D アセットパイプライン（2.0）

キャンプの実在物は「Three.js のプリミティブを組み合わせた手続きモデル」から、**Blender で制作した `.glb` の正式アセット**へ段階的に置き換えています：

- 監査：[`docs/model-audit.md`](docs/model-audit.md) —— 各小道具の生成関数、ジオメトリ、マテリアル、アニメーション／操作との依存、必須アンカー
- アートディレクション：[`docs/art-direction.md`](docs/art-direction.md) —— 静かで温かく、使い込まれ、少し風雨にさらされた写実的な夜のキャンプ。冷たい月光 + 暖かい焚き火
- パイプライン仕様：[`docs/asset-pipeline.md`](docs/asset-pipeline.md) —— 座標基準、モデル契約、PBR、性能予算、段階計画
- ランタイム：`src/assets/AssetManager.js`（GLTFLoader の読み込み／キャッシュ／インスタンス化）+ `src/assets/ModelRegistry.js`（ノード契約）
- ソース：`tools/blender/*.py`（再現可能な Blender ビルドスクリプト）→ `assets/source/*/*.blend` → `assets/models/*.glb`

| 段階 | モデル | 状態 |
|---|---|---|
| Stage 1 | テント | ✔ `assets/models/tent.glb`（帆布の織り目、縫い目、張力のしわ、巻き上げた入口、張り綱、生活感のある室内；約 2.6 万三角形、1.3 MB） |
| Stage 2 | バックパック、椅子 | ✔ `backpack.glb`（荷物の詰まった柔らかな本体、面に沿うコンプレッションストラップ、バックル、バンジーコード、マット、縫い目；約 1.5 万三角形、1.4 MB）· `chair.glb`（X フレームのキャンプチェア、たわんだ座面／背布、スリーブ、ドリンクホルダー；約 6 千三角形、0.7 MB） |
| Stage 3 | ランタン | ✔ `lantern.glb`（ハリケーンランタン：プレス成形のタンク、左右の給気管、フード、真鍮バーナーと芯ノブ、ワイヤーガード内のガラスホヤ、ハンドル；ホーロー塗装の剥げと煤；約 1.1 万三角形、0.7 MB） |
| Stage 4 | ケトル + スタンド | 予定 |
| Stage 5 | 松明、松ぼっくり、薪、斧、薪割り台など | 予定 |

アセットの再生成（Blender 4.x、または `pip install bpy`）：

```bash
blender --background --python tools/blender/build_tent.py      # assets/models/tent.glb と assets/source/tent/tent.blend を出力
blender --background --python tools/blender/build_backpack.py  # backpack.glb + assets/source/backpack/backpack.blend
blender --background --python tools/blender/build_chair.py     # chair.glb + assets/source/chair/chair.blend
blender --background --python tools/blender/build_lantern.py   # lantern.glb + assets/source/lantern/lantern.blend
```

`assets/source/<名前>/<名前>.blend` を直接編集し、`docs/asset-pipeline.md` §6 の設定で `assets/models/<名前>.glb` に書き出すこともできます。
正式アセットの読み込みに失敗した場合（ファイルがない等）は、元の手続きモデルに自動で戻ります。

## Blender 連携（手続きモデル）

シーン内のモデルは **glTF 2.0（.glb）** として書き出し、Blender で開いて調整し、ページに戻して手続き生成モデルと置き換えられます。

### 1. 書き出し

パラメータパネル下部の **「Blender モデル」**：対象を選び **.glb 書き出し** をクリックすると `<名前>.glb` がダウンロードされます。

| 対象 | 内容 | ページへ戻せるか |
|---|---|---|
| シーン全体（現在） | 現在の森／海辺の環境 + キャンプ + 焚き火 + ライト + カメラ | — |
| 地形 | 現在のシーンの地面メッシュ | — |
| 遠くの山（森） / 海岸の丘と岩礁 | 遠景の山体 + 林帯シルエット | ✓ |
| トウヒ / マツ / ヤシ | 1 本分の樹木テンプレート（根元が原点、高さ約 7〜9 m） | ✓ その樹種をすべて置き換え |
| テント / 椅子 / バックパック / ランタン | シーン内のモデル（すでに正式 GLB アセット） | —（`assets/source/<名前>/<名前>.blend` を編集） |
| 薪の山 / 薪割り台と斧 / マグ | 単体の小道具（自身の原点基準） | ✓ |
| 焚き火（石と薪） | 石、薪、熾火 | —（薪に崩れるアニメーションがあるため） |

`assets/models/procedural/` には置き換え可能な 8 モデルの .glb が同梱されており、そのまま Blender で開けます。

### 2. Blender で開く

`ファイル ▸ インポート ▸ glTF 2.0 (.glb/.gltf)`。単位はメートル、Y-up は Blender の Z-up に自動変換され、マテリアルは Principled BSDF になります。書き出し時の処理：

- 炎のパーティクル、星空、月、きらめきなどの実行時エフェクトは書き出さない
- インスタンス化したオブジェクト（背景林、小石など）は**リンク複製**になり、1 つ編集すると全体に反映
- バンプマップは法線マップに変換、法線マップの緑チャンネルは glTF 規約に補正済み
- 樹木と山は**頂点カラー**で陰影を表現（マテリアル内の Color Attribute ノード）
- オブジェクトとマテリアルには読みやすい名前（例：`Tree_spruce_03 › Spruce › Foliage`、`TentFabric`）

### 3. 調整後にページへ戻す

1. Blender で `ファイル ▸ エクスポート ▸ glTF 2.0`、形式は **glTF Binary (.glb)**、`assets/models/procedural/` に**同じ名前**で保存（例：`mug.glb`）
2. `assets/models/procedural/models.json` の該当項目を `true` に変更（ファイル名も指定可、例：`"mug": "mug_v2.glb"`）
3. ページを再読み込み（HTTP サーバー経由）。ブラウザのコンソールに `[models] mug ← assets/models/procedural/mug.glb` と表示されます

注意：

- **ルートオブジェクトは原点のまま動かさない**：配置と向きはページ側が決め、ファイルはモデル自体だけを表します
- 薪割り台：斧のオブジェクト名は `Axe`（薪割りアニメーションに使用）。削除した場合は手続き生成の斧を使います
- エクスポート時に `Include ▸ Custom Properties` を有効にすると `noCastShadow` などの影設定が保持されます
- ライトの強度単位は Blender と異なります。シーン全体を読み込んで明るさが合わない場合は、インポート設定の `Lighting Mode` で調整してください

## プロジェクト構成

```text
Campfire/
├── index.html
├── README.md
├── README.zh-CN.md
├── README.ja.md
├── docs/                # モデル監査、アートディレクション、アセットパイプライン仕様
├── src/assets/          # AssetManager.js、ModelRegistry.js
├── tools/blender/       # Blender アセットビルドスクリプト（bpy）
├── assets/
│   ├── textures/
│   ├── models/          # 正式 .glb アセット（テント、バックパック、椅子、ランタン …）
│   │   └── procedural/  # 手続きモデルの書き出し + models.json（置き換え設定）
│   └── source/          # アセットのソースファイル（.blend）
├── scripts/
└── .claude/
```
